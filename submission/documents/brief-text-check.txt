THE DEMONSTRATED MESSAGE
!rule Every third coin flips gravity for 4 seconds
WHAT ACTUALLY CHANGES
On each third coin, acceleration reverses and the player rises toward the solid ceiling. Four seconds
later, normal gravity returns automatically. A repeat trigger refreshes the effect timer; it never stacks a
permanent reversal.
STREAMER CONTROL AND INPUT LIMITS
Approval is explicit. Chat cannot activate a rule by itself. One approved rule controls one active round.
The parser is constrained. Supported triggers are 2-10 coins and durations are 1-6 whole seconds.
Unsupported requests cannot be approved; chat is never executed as code.
Attribution stays attached. The proposal, rule, originating message and author remain traceable. A
downloadable controller record preserves bounded observed events.
Milestone scope: one local streamer, one backend process and one arena. No runtime AI provider or paid inference is
required.

LOCAL EVALUATION
Use Node 24+, Go 1.26+ and an existing PostgreSQL 18 server with dedicated application/test databases. Install
web dependencies with npm ci in web/. Copy the backend environment example without overwriting existing
settings, then configure database URLs and your own Twitch app credentials privately.
node scripts/doctor.mjs
node scripts/verify.mjs
node scripts/dev.mjs --live
Open http://localhost:5174, connect the broadcaster account, send the example rule in that real channel and use A/D or
arrow keys plus Space. The exact OAuth callback is http://localhost:8080/auth/twitch/callback. Keep tokens and
credentials out of submission materials.
